# Speech A2 deck notice

The Speech > A2 section is converted from the user-supplied
`Basic_German-English_conversational_phrases_to_get_by.apkg` package. The Anki
deck calls itself `German basics to get by`. It contains 157 notes and 154 MP3
recordings. Two duplicate note pairs were merged into 155 practice cards.

The source incorrectly links the Sunday card to the Saturday recording. That
card uses the browser's German speech synthesis instead. The other 154 cards
use the recordings packaged in the APKG.

The package contains no license metadata. The user who supplied it confirmed
permission to publish the converted phrases and audio in this repository on
October 25, 2026. That confirmation does not establish a general license for
third-party reuse.
