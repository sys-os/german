# Dark S01E01 deck notice

The `Dark S1E1` study tab is a local conversion of the user-supplied
`Dark_TV_series_english-german_S01E01.apkg` Anki package.

The package contains dialogue, audio clips, and scene images from the television
series *Dark*. No redistribution license was included with the package. These
assets are presumed copyrighted and should not be published or redistributed
with the application without permission from the relevant rights holders.

The source package contains 311 German-English dialogue cards. Each card has an
OGG audio clip and a JPG scene still. Its Anki `Video` fields are empty, so the
source package does not include video files.
