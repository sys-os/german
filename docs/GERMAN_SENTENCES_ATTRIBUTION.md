# German Sentences deck attribution

The optional **Sentences** tab is a local conversion of the AnkiWeb shared deck
**German Sentences** (shared item `785874566`), updated March 8, 2024.

- Source: https://ankiweb.net/shared/info/785874566
- Author notice included in the deck: "Neri - 2021 All rights reserved."
- Imported content: 1,500 Read cards, 1,500 Speak cards, and 500 referenced audio files.
