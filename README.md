# german
repo for learning german

## GitHub Pages build

This public build includes the vocabulary, Pareto, Speech A2, irregular-verb, modal-verb, save-state, exclusion, stats, and Pokedex features. It is responsive for desktop and phone use.

The local-only Connectors, Sentences, and Dark S1E1 deck payloads are intentionally excluded because their source packages do not grant public redistribution rights. Their importer code and attribution notes remain in the repository so licensed data can be used in a local checkout.

## Bundled data attribution

The optional Pareto tab includes converted data from German Pareto Deck v0.3. See [docs/GERMAN_PARETO_ATTRIBUTION.md](docs/GERMAN_PARETO_ATTRIBUTION.md) for source and license details.

The local-only Sentences integration supports a conversion of the AnkiWeb "German Sentences" deck. Its source does not grant redistribution rights; see [docs/GERMAN_SENTENCES_ATTRIBUTION.md](docs/GERMAN_SENTENCES_ATTRIBUTION.md) before publishing any build containing that data or audio.

The local-only Dark S1E1 integration supports a user-supplied Anki package containing copyrighted television dialogue, audio, and scene images. See [docs/DARK_S01E01_ATTRIBUTION.md](docs/DARK_S01E01_ATTRIBUTION.md); do not redistribute those assets without permission.

The local-only Connectors integration supports a user-supplied German conversation-connectors Anki deck. See [docs/CONVERSATION_CONNECTORS_ATTRIBUTION.md](docs/CONVERSATION_CONNECTORS_ATTRIBUTION.md) before redistributing it.

The Speech A2 section includes converted phrases and recordings from a user-supplied Anki package. The user confirmed permission to publish these assets in this repository; see [docs/SPEECH_A2_ATTRIBUTION.md](docs/SPEECH_A2_ATTRIBUTION.md).
